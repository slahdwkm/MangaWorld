# Manga World – Android MVP

مشروع أولي لقارئ مانجا Android باستخدام Kotlin وJetpack Compose.

## ما يعمل في هذه النسخة
- بحث مباشر في فهرس MangaDex.
- عرض أغلفة وملخصات الأعمال.
- عرض الفصول المتاحة باللغة الإنجليزية.
- قارئ صفحات بتمرير عمودي.
- حفظ معرفات المفضلة محلياً.
- تبديل الوضع الداكن والفاتح وحفظ الاختيار.

## المتطلبات
- Android Studio حديث.
- JDK 17 أو أحدث.
- Android SDK 36.
- اتصال إنترنت.

## بناء APK
1. فك ضغط المشروع.
2. افتح مجلد `MangaWorld` في Android Studio.
3. انتظر Gradle Sync وتنزيل المكتبات.
4. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ستجد الملف عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات مهمة
- هذه نسخة MVP أولية وليست إصداراً نهائياً.
- البحث والفصول في هذه النسخة مهيآن للغة الإنجليزية؛ دعم العربية يحتاج التأكد من توفر ترجمات عربية في المصدر.
- لم تُنفذ بعد إدارة تنزيلات دون اتصال، سجل القراءة، مزامنة المفضلة أو فلاتر التصنيف.
- MangaDex مصدر فهرسة ومحتوى تابع لجهات رفع/ترجمة مختلفة. يجب الالتزام بشروط الاستخدام، وإظهار نسب المصدر ومجموعات الترجمة عند توفرها، واحترام طلبات إزالة المحتوى. لا تضف إعلانات أو خدمات مدفوعة على محتوى MangaDex دون إذن صريح وفق سياساته.
- لا يضمن المشروع توفر كل عنوان أو كل فصل في كل بلد أو لغة.


## بناء APK من الهاتف عبر GitHub Actions
يوجد workflow في `.github/workflows/android-apk.yml`:
1. أنشئ مستودعاً جديداً على GitHub باسم `MangaWorld`.
2. ارفع محتويات هذا المجلد إلى الفرع `main` (لا ترفع ملف ZIP نفسه كمصدر وحيد).
3. افتح تبويب Actions في المستودع وفعّل Actions إذا طُلب ذلك.
4. شغّل `Build Manga World APK` أو انتظر انتهاء البناء بعد رفع الملفات.
5. افتح تشغيل workflow الناجح، ثم نزّل Artifact باسم `MangaWorld-debug-apk`.
6. فك ضغط الـ Artifact وثبّت `app-debug.apk` على هاتف Android.

الـ workflow يستخدم GitHub-hosted runner؛ لا يحتاج إلى تثبيت Android Studio على الهاتف.
